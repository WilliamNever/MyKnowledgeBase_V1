Commands to create/start/stop/delete a windows service
ref - https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/sc-create

Create and start windows service -
rem start=delayed-auto
sc.exe create "ServiceName" binPath="path to service.exe file" start=auto
sc.exe start "ServiceName"

Stop and delete windows service -
sc.exe stop "ServiceName"
sc.exe delete "ServiceName"
